# Peekaboo Post

Interactive digital invitations that guests love to open. Tap, peek, party!

**Website:** [peekaboopost.com](https://peekaboopost.com)

## What this is
The website for Peekaboo Post. Hosts pick a tap-to-open invitation, customize it, share one link, and track RSVPs in one place, with no paper and no postage.

## Status
🚧 Getting started. The first piece will be a "coming soon" page with an email signup.
